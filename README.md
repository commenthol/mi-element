# mi-element

Monorepo for mi-element a lightweight un-opinionated alternative to write and use [Web Components][].

- [mi-element](https://github.com/commenthol/mi-element/blob/main/packages/mi-element/README.md) - Build lightweight reactive micro web-components
- [mi-html](https://github.com/commenthol/mi-element/blob/main/packages/mi-html/README.md) - html`` literal for building reactive web components
- [mi-signal](https://github.com/commenthol/mi-element/blob/main/packages/mi-signal/README.md) - signal and effect for mi-elements reactivity
- [mi-intl](https://github.com/commenthol/mi-element/blob/main/packages/mi-intl/README.md) - i18n for mi-element
